## Week 1 Practice Problems Overview

| Problem | Description | Primary Concepts |
|---------|-------------|------------------|
| **1. Rock-Paper-Scissors Game** | Simulates 5 rounds between player and computer with tabular results and win percentage. | Random numbers, loops, formatted tabular output, statistics |
| **2. Palindrome Checker** | Verifies palindrome strings using 3 independent approaches (Iterative, Recursive, Array Reversal). | Loops, recursion, array manipulation, string comparison |
| **3. BMI Calculator for a Team** | Calculates BMI and classifies status for team members in a wellness report table. | Parallel arrays, arithmetic, status classification, tabular output |
| **4. First Non-Repeating Character** | Finds the first character appearing only once in a string. | Character frequency counting, HashMap, early-exit scanning |
| **5. Reverse Customer Name** | Reverses customer names character-by-character preserving original string immutability. | String traversal, character array manipulation |

## Quick Start / How to Run

Compile and execute any problem using standard Java tools:

```cmd
# Navigate into the Step_Assignments root directory
cd Step_Assignments

# Compile Week 1 Practice Problems
javac week_1/practice_problems/*.java

# Run individual problems:
java -cp week_1/practice_problems Problem1_RockPaperScissors
java -cp week_1/practice_problems Problem2_PalindromeChecker
java -cp week_1/practice_problems Problem3_BMICalculator
java -cp week_1/practice_problems Problem4_FirstNonRepeatingChar
java -cp week_1/practice_problems Problem5_ReverseCustomerName
```
