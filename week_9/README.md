# Week 9 - Abstraction & Interfaces (Category C)

This folder contains Java implementations for Week 9 covering **Abstraction, Abstract Classes, and Interfaces**.

---

## Folder Structure

- **[`assignment_problems/`](./assignment_problems)**: Contains 5 coding assignment problems.
  1. `Problem1_MovieTicketCounter.java` - Movie ticket booking with shared convenience fee.
  2. `Problem2_ParcelShippingDesk.java` - Shipping desk with `Insurable` interface for parcel insurance.
  3. `Problem3_CollegeFeeCounter.java` - Student tuition and `BusServiceable` transport fee calculation.
  4. `Problem4_CityCabFareMeter.java` - Cab fare calculation with `NightServiceable` interface.
  5. `Problem5_HomeApplianceEnergyReport.java` - Energy report with `SaverModeCapable` interface.

- **[`practice_problems/`](./practice_problems)**: Contains 5 coding practice problems along with Part B Quiz and Part C Concept Questions.
  1. `Problem1_GardenPlotAreaReport.java` - Plot area calculation using abstract class `Plot`.
  2. `Problem2_WeeklyStaffPay.java` - Staff payroll system for full-time, hourly, and intern staff.
  3. `Problem3_LibraryLateFineCounter.java` - Library item fine counter.
  4. `Problem4_ElectricityConnectionBilling.java` - Monthly electricity billing across connection types.
  5. `Problem5_TravelBookingCommonFee.java` - Travel booking with shared booking fee.
  6. `README.md` - Complete Solutions for Part B Quiz (Q1-Q10) and Part C Concept Questions (Q1-Q5).
