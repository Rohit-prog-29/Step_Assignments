# Week 8 - Assignment Problems (Category C)

This folder contains solutions for Week 8 Coding Assignment problems focusing on **Inheritance** and **Polymorphism**.

## Problems Overview

1. **Problem 1: The Canteen Billing Counter** ([`Problem1_CanteenBillingCounter.java`](./Problem1_CanteenBillingCounter.java))
   - Polymoic billing system with Student (10% discount), Staff (5% discount), and Guest (full amount + ₹10 fee).
2. **Problem 2: The Campus Parking Charge Calculator** ([`Problem2_CampusParkingChargeCalculator.java`](./Problem2_CampusParkingChargeCalculator.java))
   - Parking charge calculator for Bike (₹10/hr), Car (₹30 1st hr + ₹20 additional hr), and Truck (₹50/hr, min ₹100).
3. **Problem 3: The Hostel Electricity Bill** ([`Problem3_HostelElectricityBill.java`](./Problem3_HostelElectricityBill.java))
   - Hostel electricity billing for Single room (₹8/unit), Shared room (₹6/unit split among occupants), and AC room (₹10/unit + ₹200 fixed fee).
4. **Problem 4: The Festival Bonus Calculator** ([`Problem4_FestivalBonusCalculator.java`](./Problem4_FestivalBonusCalculator.java))
   - Payroll bonus calculation for Fulltime (10% salary), Parttime (5% salary), and Intern (₹2000 fixed).
5. **Problem 5: The Streaming Plan Renewal Reminder** ([`Problem5_StreamingPlanRenewalReminder.java`](./Problem5_StreamingPlanRenewalReminder.java))
   - Renewal date calculation for Basic (30 days), Standard (90 days), and Premium (365 days) subscription plans using `java.time.LocalDate`.
